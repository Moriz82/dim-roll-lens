# Credits

Thank you, **[Maxeption](https://github.com/Maxeption)**, for creating **[dim-aegis-overlay](https://github.com/Maxeption/dim-aegis-overlay)** and making it available under MIT, as declared in its README. Roll Lens builds directly on that work. Its DIM React bridge, spreadsheet parsing, original evaluation engine, advanced settings, translations, armor analysis, and explorer come from Maxeption and the upstream contributors. The upstream Git history is preserved.

Roll Lens adds the activity verdict engine, explicit simultaneous PvE/PvP labels, strict matching option, perk-swap distinction, inventory dashboard, simpler settings, new visual identity, offline initialization, and release validation. It is an independent community project, not an official release from Maxeption or DIM.

- **[Aegis](https://docs.google.com/spreadsheets/d/1JM-0SlxVDAi-C6rGVlLxa-J1WGewEeL8Qvq4htWZHhY/edit)**: PvE recommendations and analysis.
- **[Finnald / Pride Eternal](https://docs.google.com/spreadsheets/d/1TVgtTRWNGEPi6OMlTLxXFSKUTi_ycwykhwuw8EW_jJ0/edit)**: PvP recommendations and analysis.
- **[LowCo and Azra](https://docs.google.com/spreadsheets/d/14LnzOhmeXzKaSV3OR35pQJkclg6vLC4YmKtlKTctY3o/edit)**: armor set analysis retained from upstream.

- **[MrCharles / DIMAegisWeaponWishlist](https://github.com/charlesxcaliber/DIMAegisWeaponWishlist)**: optional Aegis wishlist.
- **[Destiny Item Manager](https://github.com/DestinyItemManager/DIM)** and **Bungie**: inventory application and game definitions.
- **Light.gg**: optional community popularity grades retained in advanced settings; these grades do not establish Roll Lens god-roll verdicts.
